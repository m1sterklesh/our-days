# Our Days

Нежный календарь на двоих. Чистый HTML, CSS и JavaScript без библиотек.

## Что умеет

- **Месяц:** до 3 задач в ячейке цветом владельца. Задачу можно перетащить на другой день, двойной клик по дню создаёт новую.
- **Неделя** (на телефоне — **день**): сетка часов, блоки по времени, строка «весь день».
  - Блок тянется за середину (другое время или день, шаг 15 минут) и за нижний край (длительность).
  - Клик по пустому месту — задача на час, протяжка — на выделенный отрезок.
  - На телефоне перетаскивание по долгому нажатию, свайп влево/вправо листает дни.
- **Панель дня:** справа на компьютере, выезжает снизу на телефоне. Отметка «выполнено», удаление с подтверждением.
- **Чьё:** у каждой задачи есть владелец (первый, второй или «вместе»), у каждого свой цвет. Сверху фильтр.
- **Два режима:**
  - **локальный** — пока Supabase не настроен: всё хранится в браузере, вход по коду `520` (только для атмосферы, не защита);
  - **облачный** — общий календарь на двух устройствах, настоящий вход по почте и паролю.

## Подключение Supabase (один раз)

1. Зарегистрируйся на [supabase.com](https://supabase.com) и создай проект (Free). Регион — ближайший, например Frankfurt.
2. **SQL Editor** → вставь содержимое [`supabase/schema.sql`](supabase/schema.sql) → **Run**.
3. **Authentication → Sign In / Providers** → выключи **Allow new users to sign up**. Без этого кто угодно сможет зарегистрироваться. Данные он всё равно не увидит, но лишние аккаунты ни к чему.
4. **Authentication → Users → Add user → Create new user**: создай двух пользователей (почта + пароль, галочка *Auto Confirm User*).
5. Снова **SQL Editor**: раскомментируй блок `insert into public.members` внизу `schema.sql`, подставь почты, имена и цвета, выполни.
6. **Project Settings → API**: скопируй *Project URL* и *anon public* (или *publishable*) ключ в `js/config.js`:

   ```js
   SUPABASE_URL: 'https://xxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJ...',
   ```

Задачи, созданные в локальном режиме, при первом входе автоматически перенесутся в облако.

## Напоминания (push)

В каждой задаче можно выбрать «Напомнить»: в момент начала, за 10/15/30 минут, за час или за день. Задачи без времени напоминают от 9:00. Уведомления приходят на все подписанные устройства обоих.

Как это устроено: `pg_cron` раз в минуту вызывает Edge Function `send-reminders`, она находит подошедшие напоминания и шлёт Web Push. Каждое напоминание отправляется один раз, после переноса задачи — заново.

Включить на устройстве: колокольчик в шапке → «Включить» → «Проверить». На iPhone — только из иконки на экране «Домой» (iOS 16.4+).

Настройка сервера (один раз):

1. `npx web-push generate-vapid-keys` — публичный ключ в `js/config.js` (`VAPID_PUBLIC_KEY`).
2. `npx supabase login` (в обычном терминале), затем
   `npx supabase secrets set --project-ref <ref> VAPID_PUBLIC_KEY=… VAPID_PRIVATE_KEY=… VAPID_SUBJECT=mailto:… CRON_SECRET=…`
3. `npx supabase functions deploy send-reminders --project-ref <ref> --no-verify-jwt --use-api`
4. В `supabase/reminders.sql` заменить `CRON_SECRET_HERE` на тот же `CRON_SECRET` и выполнить в SQL Editor.

## Безопасность

- Ключ `anon` публичный по замыслу Supabase. Данные защищают политики Row Level Security: читать и писать может только вошедший пользователь, у которого есть строка в `members`.
- Регистрация выключена, аккаунты создаются вручную.
- Имена хранятся в базе, а не в коде.
- Страница помечена `noindex`, поисковики не будут её показывать.
- Бесплатный проект Supabase засыпает после 7 дней без запросов. Данные не теряются, проект будится кнопкой в панели.

## Структура

```
├── index.html
├── css/style.css
├── js/
│   ├── config.js    — URL и ключ Supabase, имена по умолчанию
│   ├── api.js       — вход, обновление токена, REST-запросы через fetch
│   ├── tasks.js     — хранилище: кеш localStorage, оптимистичные правки, синхронизация
│   ├── drag.js      — перетаскивание (мышь и палец)
│   ├── calendar.js  — даты и месячная сетка
│   ├── week.js      — сетка часов, перетаскивание и растягивание блоков
│   ├── gate.js      — «дверь» со входом
│   └── main.js      — состояние, панель дня, формы, фильтры
└── supabase/schema.sql
```

Работает и по двойному клику на `index.html`, и с хостинга.
